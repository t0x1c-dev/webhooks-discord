# Proton Services

![Proton Services](https://raw.githubusercontent.com/t0x1c-dev/webhooks-discord/refs/heads/main/IMAGES/image%20(15).png)

Free browser tools for Discord message building. Components V2 and classic embeds. Preview live, export JSON, send through your own webhook. Nothing leaves your tab unless you hit send.

**Live site:** [discordmessagebuilder.vercel.app](https://discordmessagebuilder.vercel.app)

---

## What's in it

- **Components V2 Builder** — containers, sections, text, media, buttons, selects, separators. Nested building. Live preview.
- **Embed Builder** — multi-embed, author, fields, color, images, footer, timestamp. Still works. Feature updates are frozen; UI can still get polish.
- **Import / export JSON** — bring stuff in, take it out.
- **Webhook send** — paste your URL, send from the browser.
- **Mobile layout** — drawers, bottom bar, usable on phone.
- **TOS gate, changelog, credits**

## Notes

- Webhook URLs stay in your browser. If one leaks (screenshot, share, malware, etc.), that's on you. Rotate it in Discord if needed.
- Preview is close to Discord, not a perfect clone. Discord can change layout and rules anytime.
- Interactive components (non-link buttons, selects) usually need a bot. Webhooks alone won't fully drive those.
